# Intelligent-robust-control-design-for-a-3-DoF-industrial-manipulator
Industrial robotic arm control system (ABB IRB1600-based, 3-DoF) using adaptive sliding-mode control and neural-network disturbance estimation. Achieves sub-millisecond convergence and &lt;0.003 tracking error under real-world disturbances — built for high-precision manufacturing and automation applications. MATLAB/Simulink.
